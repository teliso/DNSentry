# 过滤规则

## 规则语法

规则保存在本地规则文件（默认 `data/rules.txt`）和远程规则源里，每行一条：

```text
example.com                  # 拦截 example.com 及其所有子域名
||ads.example.com^           # AdGuard 语法，同上
@@||trusted.example.com^     # 放行（覆盖拦截）
0.0.0.0 a.example b.example  # hosts 语法，一行可以有多个域名
# 以 # 或 ! 开头的是注释
```

- 一条规则总是**匹配这个域名及它的所有子域名**：拦截 `example.com` 也会拦截 `www.example.com`。
- hosts 语法只识别指向 `0.0.0.0`、`127.0.0.1`、`::`、`::1` 的条目（拦截类）；指向其他地址的条目会被忽略；`localhost`、`broadcasthost` 等系统名称永远不会被拦截。
- **不支持**：带修饰符的规则（如 `||x.com^$third-party`）、通配符（`*.example.com`）、正则表达式、元素隐藏规则。这些行会被忽略。在控制台保存 `rules.txt` 时，无法识别的行会列出行号。

## 优先级

同一个域名有多条规则时：

1. **最具体的域名优先**：`@@||safe.example.com^` 放行了 `safe.example.com`，即使 `||example.com^` 拦截了上级域名。
2. **本地规则优先于规则源**：你在本地放行的，规则源里再怎么拦截也不管用；本地拦截的同理。
3. **同一来源里，放行优先于拦截**，与规则出现的先后无关。

过滤规则**在缓存和上游之前**执行，所以改规则后下一次查询就生效，不需要清缓存。

## 本地规则

- **控制台**：“过滤规则”页可以逐条添加 / 删除，也可以“编辑 rules.txt”整个文件。
- **直接改文件**：改完后在控制台点“从磁盘重新载入”，或调用 `POST /api/reload`。
- 添加已存在的规则会提示重复；删除 hosts 行里的某一个域名时，会保留同一行的其他域名。

## 规则源

订阅在线列表，例如 AdGuard DNS 过滤器（AdGuard 语法）或各种 hosts 列表。

- **添加**：“规则源”页填写地址、名称（可选）、更新频率。添加后立即下载。
- **缓存**：下载的列表保存在规则文件所在目录的 `remote/` 下，重启后立即可用，不需要等下载。
- **更新**：到期后使用 `ETag` / `Last-Modified` 条件请求，列表没变时服务器返回 304，不会重复下载；也可以手动“更新”。
- **失败处理**：下载失败时继续使用上一次成功的版本，控制台显示错误原因，10 分钟后（更新间隔更短则按间隔）重试。连续一天以上没有成功更新，页面顶部会出现提醒。
- **停用 / 删除**：停用会立即撤下规则并保留缓存；删除会连缓存一起清除。
- 单个列表最大 32 MB；最多 64 个规则源；地址必须是 `http://` 或 `https://`。

## 规则检测与排查

“某个网站打不开”时：

1. 打开 **查询日志**，搜索这个域名，看它的处理结果和所依据的规则。
2. 如果被拦截，点行右侧的 **放行**；或者到“过滤规则 → 规则检测”输入域名，看所有匹配的规则，决定是删除本地规则、添加放行，还是停用某个规则源。
3. 放行后立即生效；如果浏览器仍然打不开，多半是浏览器或系统自己缓存了拦截结果，等几秒或清一下 DNS 缓存。

## 被拦截时返回什么

在“DNS 设置 → 拦截响应”里选择：

| 模式 | 应答 |
| --- | --- |
| NXDOMAIN（默认） | 域名不存在，并带负缓存 SOA |
| 默认 / 空 IP | A 返回 `0.0.0.0`，AAAA 返回 `::` |
| 自定义 IP | 返回你指定的 IPv4 / IPv6 地址 |
| REFUSED | 拒绝，客户端通常不缓存 |

被拦截的域名，任何类型的查询（A、AAAA、HTTPS 等）都在本机直接应答，不会发往上游。“拦截响应 TTL”决定客户端缓存这个结果的时间。
