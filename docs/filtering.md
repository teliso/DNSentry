# 过滤规则

## 规则语法

规则保存在本地规则文件（默认 `data/rules.txt`）和远程规则源里，每行一条：

```text
example.com                  # 拦截 example.com 及其所有子域名
||ads.example.com^           # AdGuard 语法，同上
@@||trusted.example.com^     # 放行（覆盖拦截）
0.0.0.0 a.example b.example  # hosts 语法，一行可以有多个域名
# 以 # 或 ! 开头的是注释
```

- 一条规则总是**匹配这个域名及它的所有子域名**：拦截 `example.com` 也会拦截 `www.example.com`。
- hosts 语法只识别指向 `0.0.0.0`、`127.0.0.1`、`::`、`::1` 的条目（拦截类）；指向其他地址的条目会被忽略；`localhost`、`broadcasthost` 等系统名称永远不会被拦截。
- **不支持**：带修饰符的规则（如 `||x.com^$third-party`）、通配符（`*.example.com`）、正则表达式、元素隐藏规则。这些行会被忽略。在控制台保存 `rules.txt` 时，无法识别的行会列出行号。

## 优先级

同一个域名有多条规则时：

1. **最具体的域名优先**：`@@||safe.example.com^` 放行了 `safe.example.com`，即使 `||example.com^` 拦截了上级域名。
2. **本地规则优先于规则源**：你在本地放行的，规则源里再怎么拦截也不管用；本地拦截的同理。
3. **同一来源里，放行优先于拦截**，与规则出现的先后无关。

过滤规则**在缓存和上游之前**执行，所以改规则后下一次查询就生效，不需要清缓存。

## 本地规则

- **控制台**：“过滤规则”页可以逐条添加 / 删除，也可以“编辑 rules.txt”整个文件。
- **直接改文件**：改完后在控制台点“从磁盘重新载入”，或调用 `POST /api/reload`。
- 添加已存在的规则会提示重复；删除 hosts 行里的某一个域名时，会保留同一行的其他域名。

## 规则源

订阅在线列表，例如 AdGuard DNS 过滤器（AdGuard 语法）或各种 hosts 列表。

- **添加**：“规则源”页填写地址、名称（可选）、更新频率。添加后立即下载。
- **缓存**：下载的列表保存在规则文件所在目录的 `remote/` 下，重启后立即可用，不需要等下载。
- **更新**：到期后使用 `ETag` / `Last-Modified` 条件请求，列表没变时服务器返回 304，不会重复下载；也可以手动“更新”。
- **失败处理**：下载失败时继续使用上一次成功的版本，控制台显示错误原因，10 分钟后（更新间隔更短则按间隔）重试。连续一天以上没有成功更新，页面顶部会出现提醒。
- **停用 / 删除**：停用会立即撤下规则并保留缓存；删除会连缓存一起清除。
- 单个列表最大 32 MB；最多 64 个规则源；地址必须是 `http://` 或 `https://`。

## 规则检测与排查

“某个网站打不开”时：

1. 打开 **查询日志**，搜索这个域名，看它的处理结果和所依据的规则。
2. 如果被拦截，点行右侧的 **放行**；或者到“过滤规则 → 规则检测”输入域名，看所有匹配的规则，决定是删除本地规则、添加放行，还是停用某个规则源。
3. 放行后立即生效；如果浏览器仍然打不开，多半是浏览器或系统自己缓存了拦截结果，等几秒或清一下 DNS 缓存。

## 屏蔽整个服务

“过滤 → 服务屏蔽”里内置了常见网站和应用的域名清单（TikTok、抖音、快手、哔哩哔哩、YouTube、Netflix、Facebook、Instagram、X、Reddit、Telegram、Discord、Steam、Roblox、Minecraft 等），打开开关就会拦截它的全部域名及子域名，不需要自己找域名。

- 你自己的**放行规则优先**：例如屏蔽了 TikTok，又写了 `@@||allowed.tiktok.com^`，这个域名仍然可以访问。
- 暂停过滤期间不生效。
- 被屏蔽的请求在日志里显示为“已拦截”，规则一栏是“服务：TikTok”。
- 清单是通用域名列表，可能漏掉某个服务较新的域名；漏掉的可以用本地规则补充。

## 计划任务

“过滤 → 计划”可以让屏蔽按时间自动生效，窗口结束后自动恢复。例如“每晚 22:00 到次日 07:00 屏蔽游戏”“工作日 9:00–17:00 屏蔽视频”。每条计划包含：

- **星期**：选哪几天（不选 = 每天）；**开始 / 结束时间**（24 小时制）。
  - 结束时间**早于**开始时间表示窗口跨过午夜，并且属于它**开始的那一天**：周五 22:00 – 07:00 包括周六凌晨，不包括周五凌晨（那属于周四的窗口）。
  - 开始和结束相同表示全天。
- **屏蔽的服务**（可多选）和**同时强制安全搜索**（可选）：窗口内生效，窗口外不生效。
- **时区**（页面上方，所有计划共用）：留空用服务器的本地时间——容器里通常是 UTC，容易和你的时间差几个小时，建议填 `Asia/Shanghai` 这类名称；页面会显示按该时区计算的“现在时间”。

规则：你自己的**放行规则优先**；暂停过滤期间计划里的屏蔽不生效；被计划屏蔽的请求在日志里显示为“已拦截”，规则一栏是“计划「名称」：服务名”。窗口开关使强制安全搜索的状态变化时，缓存会被清空，避免继续返回旧状态的结果。最多 16 条计划。

## 安全搜索

打开“强制安全搜索”（或某个计划的窗口强制它）后，Google（含各国家/地区域名）、Bing、DuckDuckGo、YouTube（中等限制）、Pixabay 会被 DNS 重定向到各自的安全搜索地址（如 `forcesafesearch.google.com`），整个网络生效。这些名称的 HTTPS/SVCB 查询返回空，避免泄露未过滤的地址。浏览器自带的“安全 DNS”（DoH）会绕过它，需要在路由器上一并限制，见 [强制所有设备使用 DNSentry](enforce-dns.md)。

## 被拦截时返回什么

在“过滤 → 拦截响应”里选择：

| 模式 | 应答 |
| --- | --- |
| NXDOMAIN（默认） | 域名不存在，并带负缓存 SOA |
| 空 IP | A 返回 `0.0.0.0`，AAAA 返回 `::` |
| 自定义 IP | 返回你指定的 IPv4 / IPv6 地址 |
| REFUSED | 拒绝，客户端通常不缓存 |

被拦截的域名，任何类型的查询（A、AAAA、HTTPS 等）都在本机直接应答，不会发往上游。“拦截响应 TTL”决定客户端缓存这个结果的时间。

- **其他类型的查询**（HTTPS、MX、TXT 等）：在“空 IP / 自定义 IP”模式下返回空的 NOERROR 应答并附带 SOA（TTL 与上面相同），客户端会缓存这个“没有数据”的结果而不是反复重试。
- **扩展 DNS 错误（EDE，RFC 8914）**：客户端的查询带 EDNS 时，应答里会附上原因——命中过滤规则是 **15 Blocked**，被屏蔽的服务是 **17 Filtered**（文字里带服务名）。支持 EDE 的软件（如较新的 `dig`、部分浏览器和系统解析器）可以显示“被 DNSentry 拦截”而不是笼统的失败。`dig` 示例：`dig ads.example.com +ednsopt=15:` 会在应答的 OPT 中显示 `EDE: 15 (Blocked)`。不带 EDNS 的客户端什么额外内容都收不到。
