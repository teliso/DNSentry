# 控制台使用指南

控制台是一个单页应用，顶部导航五个页面从左到右按“监控 → 过滤 → 配置”排列：概览、日志、过滤、DNS、设置；后三个页面内部再用标签分组，地址形如 `#dns/records`，可以收藏。深色 / 浅色主题用右上角的按钮切换，手机上导航会移到底部。

页面顶部会在出现问题时显示**提醒条**：规则源长期更新失败、所有默认上游都不可用、某条域名分流的上游全部失败，或者已保存的配置需要重启才能生效。每条提醒都带跳转按钮。

## 概览

![概览](images/dashboard.png)

- **暂停过滤**（右上角）：临时关闭过滤 5 分钟 / 30 分钟 / 1 小时 / 24 小时，或直到手动恢复。暂停期间请求照常解析、缓存和记录，只是不再套用任何拦截规则；每个页面顶部都会显示提醒和“立即恢复”按钮。重启服务也会恢复过滤。
- **接入指引**：显示设备应该填写的 DNS 地址（普通 DNS，启用后还有 DoT / DoH / DoQ，可一键复制）和设置步骤。还没有任何查询时，页面会主动提示。
- **四个概览数字**：查询总数、已拦截（及占比）、缓存命中率、生效中的规则数。累计数字从本次启动开始计，卡片底部的曲线是最近 30 分钟的趋势。
- **请求趋势**：右上角可切换 30 分钟（实时，每分钟一个点）/ 24 小时 / 7 天 / 30 天 / 90 天，标题下显示所选范围的查询数、拦截数和拦截比例；鼠标悬停看具体数值。长周期数据按小时累计并保存在配置文件同目录的 `stats.json`，重启不会丢失，只记数量，不含域名和客户端。
- **上游健康**：每个上游最近 30 分钟的延迟曲线，红色竖线表示那一分钟有失败。
- **排行卡片**：请求最多的域名、被拦截最多的域名、来源客户端、上游服务器（请求数与平均耗时）、响应最慢的域名、解析失败的域名（各显示前 6 名，基于内存中的最近日志）。
- **缓存**与**安全与 DNSSEC**：命中、淘汰、预取次数，被拒绝、限速、过载、Rebinding 拦截的次数，以及 DNSSEC 验证结果。

## 日志

![查询日志](images/logs.png)

- 显示最近的请求：时间、客户端、域名、类型、处理结果、使用的上游、耗时。
- **结果** 有：已转发、缓存命中、已拦截、已放行、本地记录、限速等；被规则命中的请求会在结果下方显示**所依据的规则**，鼠标悬停显示规则来源。
- 顶部可以按域名或客户端搜索、按结果筛选；点击客户端地址会只看这个客户端。**实时刷新**开关控制第一页是否自动跟随新请求（翻到其他页时不会刷新，避免打断你）。
- 右上角“导出”把当前筛选条件下的全部内存日志下载为 CSV（可用 Excel 打开）。
- 每行右侧有快捷操作：被拦截的可以“放行”，正常转发的可以“拦截”，会为该域名（及其子域名）添加本地规则。

## 过滤

“过滤”页分四个标签：

### 规则源

![规则源](images/sources.png)

- 订阅在线的规则列表，可设置名称和更新频率（每小时到每周，或自定义分钟数）。“推荐”里的一键订阅按钮可以快速添加常用列表。
- 每个规则源显示：规则数、更新频率、内容最近更新时间、最近检查时间；失败时显示错误原因，并说明是否仍在使用缓存的规则。
- 操作：**更新**（立即拉取）、**规则**（跳转到只看这个来源的规则列表）、**编辑**、**删除**（同时清除本地缓存）；开关可以停用规则源，停用后规则立即失效但缓存保留，重新启用时无需重新下载。**全部更新**一次刷新所有已启用的规则源。

### 规则

![规则](images/rules.png)

- **规则检测**：输入一个域名，显示它最终被哪条规则处理、规则来自哪里，并列出所有匹配的规则（高亮的一条生效）。可以直接一键放行 / 拦截，或删除已有的本地放行规则。
- **添加本地规则**：输入域名或 `||域名^` 写法，选择拦截或放行。
- **全部规则**：服务端分页，可按来源（本地或某个规则源）和动作筛选，搜索域名。来自规则源的规则是只读的；本地规则可以删除。
- **编辑 rules.txt**：直接编辑整个本地规则文件，保留注释和格式；Ctrl+S 保存，保存后立即生效，无法识别的行会列出行号。**重新载入**用于在外部修改了 `rules.txt` 之后。

### 服务屏蔽

![服务屏蔽](images/services.png)

一键屏蔽整个网站或应用（TikTok、YouTube、Steam 等）的全部域名，并可打开“强制安全搜索”。你的放行规则优先于服务屏蔽。详见 [过滤规则](filtering.md#屏蔽整个服务)。这里的改动要点底部的“保存配置”。

### 拦截响应

被规则命中后返回给客户端的内容（NXDOMAIN、空 IP、自定义 IP 或 REFUSED）与 TTL。

## DNS

“DNS”页有五个标签。**除“本地记录”外，这里和“设置”页的改动都要点底部的“保存配置”才生效**；有未保存的改动时，每个页面底部都会出现保存栏。

- **上游**：主上游、备用上游、Bootstrap DNS 和请求分发策略；“测试上游”逐个测试当前填写的地址（不写入缓存）。

  ![上游](images/dns-settings.png)
- **域名分流**：让指定域名使用专属上游，见 [解析与加密 DNS](dns.md#域名分流)。

  ![域名分流](images/routes.png)
- **本地记录**：为内网设备或自定义域名直接应答（A、AAAA、CNAME、TXT），优先于缓存和上游。修改**立即保存并生效**，不需要点保存配置，也不会带上你在其他地方还没保存的修改。A / AAAA 记录还会自动生成对应的反向解析（PTR）。

  ![本地记录](images/records.png)
- **缓存**：开关、大小、TTL 上下限、预取、乐观缓存及其参数；可以清空缓存。
- **高级**：私网反向解析、禁用 AAAA、DNSSEC（请求、本地验证、信任锚）。

## 设置

“设置”页有五个标签：

- **网络与访问**：DNS 监听地址（每个地址同时绑定 UDP 和 TCP，最多 16 个，改动需要重启）；允许 / 拒绝的客户端（IP 或 CIDR）、单客户端限速、DNS Rebinding 防护。

  ![设置](images/service-settings.png)
- **控制台 HTTPS**（在“网络与访问”里）：一个开关，证书来源三选一：自动生成自签名、复用加密 DNS 的证书、单独指定证书；还可以“绑定域名”（用哪个域名打开控制台）。页面会显示当前证书的适用名称和指纹，绑定域名不在证书里时给出警告。改动需要重启。
- **控制台登录**：设置用户名和密码后，打开控制台（包括在本机）都要先登录，右上角出现“退出”按钮。修改或关闭登录需要先输入当前密码。
- **加密 DNS**：对外提供 DoT / DoH / DoH3 / DoQ / DNSCrypt，证书可以填路径或直接粘贴 PEM；运行后显示可复制的 DNSCrypt stamp。
- **日志**：内存日志条数；可选把日志按天写入文件，以及文件前缀和保留天数。
- **维护**：**配置历史**——每次保存都会记录一个版本（最多 30 个），列出**每次改了哪些设置**，可以恢复到任意版本；恢复本身也会被记录，所以可以再撤销。**导出 / 导入配置**可以把配置整份下载备份（含私钥，注意保管），或从文件导入；导入会像保存一样校验、应用并记入历史。另有版本号、配置文件路径和指标链接。

  ![配置历史](images/config-history.png)

## 手机上使用

窄屏下导航移到底部，各页面改为单列布局，常用操作（查看日志、放行 / 拦截域名、规则检测）都可以在手机上完成。

![手机布局](images/mobile.png)

## 保存与重启

- 大多数设置**保存后立即生效**。监听地址、控制台地址、规则文件路径、查询日志存储和加密 DNS 属于启动时设置，保存后会写入配置文件，但需要**重启服务**才生效——此时页面顶部会出现提醒。
- 没保存的改动不会被后台刷新覆盖；切换页面也不会丢。“放弃”按钮撤销所有未保存的改动。
